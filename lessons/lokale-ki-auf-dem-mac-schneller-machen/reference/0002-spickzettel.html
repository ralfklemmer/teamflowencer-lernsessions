Spickzettel: oMLX mit Splash

Das komplette Setup auf einer Seite – zum Ausdrucken oder für den zweiten Mac.

geprüft mit oMLX 0.7.1rc1 und Splash 1.3.2Stand 24.10.2026

Voraussetzungen

ChipM3 oder neuer (M1/M2: nur Community-Build splash-m1, ungetestet)
macOS26.4 oder neuer
Arbeitsspeichermindestens 36 GB, empfohlen 48 GB
Speicherplatzca. 25 GB für Qwen3.8-27B + Draft

Die sechs Schritte

#WasWie
1Homebrew/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)", danach die angezeigten „Next steps“ ausführen
2oMLXoMLX-<Version>-macos26-27.dmg von github.com/jundot/omlx/releases → in Programme ziehen → Get Started → API-Key → Start Server → Open Web Dashboard
3Splashbrew install incoai/tap/splash, prüfen mit splash --version (≥ 1.3.0), oMLX neu starten
4ModelleModels → Downloader → Repository ID: Jundot/Qwen3.8-27B-oQ4e-mtp und incoai/Qwen3.8-27B-DFlash2. Nicht …-Splash.
5EinlesenModels → Manager → Reload (entlädt alle Modelle)
6EinschaltenModels → Manager → Einstellungs-Symbol → Advanced Settings → Use external engine → Engine Splash → Save

Prüfen

sw_vers -productVersion                  # macOS-Version, ≥ 26.4
sysctl -n machdep.cpu.brand_string       # Chip, M3 oder neuer
brew --version                           # Homebrew vorhanden
splash --version                         # Splash ≥ 1.3.0
curl -s http://localhost:8000/health     # oMLX läuft: {"status":"healthy" …
tail -f ~/.omlx/logs/splash/*.log        # Splash live zusehen, Ende mit ctrl+C

Im Dashboard: Settings → Integration Settings → External engines zeigt Splash mit „Found automatically.“

Messen und entscheiden

  1. Bench → Modell wählen → Benchmark Context: Code (Mixed) → Run Benchmark, Splash aus.
  2. Splash einschalten, gleiche Messung wiederholen.
  3. Zeile pp1024/tg128 vergleichen: TG TPS und TTFT (ms).

Entscheidungsregel

Splash an, wenn ≥ 15 % mehr TG TPS und TTFT nicht schlechter. Sonst oMLX allein.

Frag nach

  1. Markiere eine Zeile und notiere als Kommentar deine Frage oder deinen eigenen Messwert.
  2. Öffne deinen eigenen KI-Agenten und gib ihm diese Seite als Kontext: Lass ihn die HTML-Datei lesen oder füge den Seiteninhalt in den Chat ein.
  3. Klicke oben rechts auf „Kopieren“. Dadurch landet die markierte Textstelle samt Kommentar als JSON in der Zwischenablage.
  4. Füge dieses JSON in den Chat deines KI-Agenten ein.
  5. Jetzt könnt ihr gezielt an deiner markierten Frage weiterarbeiten.
