Glossar

Jeder Begriff aus dem Tutorial in ein bis zwei Sätzen. In Klammern: das Bild aus Kapitel 01 oder der Name in der oMLX-Oberfläche.

Rund um den Mac

Terminal
Vorinstallierte Mac-App, in der du Befehle als Text eingibst statt zu klicken.
Befehl
Eine Textzeile wie splash --version, die du im Terminal mit Enter ausführst.
Eingabeaufforderung (Prompt)
Die Zeile mit % am Ende. Sie zeigt: Das Terminal wartet auf deinen nächsten Befehl.
~ (Tilde)
Kurzschreibweise für deinen Benutzerordner, zum Beispiel /Users/anna.
Homebrew
Paketmanager für den Mac: installiert und aktualisiert Programme per Befehl. Vermeiden: „brew-App“.
Tap
Eine zusätzliche Paketquelle für Homebrew, etwa incoai/tap von Inco AI.
Arbeitsspeicher (Unified Memory)
Der Speicher, den Chip und Grafik gemeinsam nutzen. Er bestimmt, wie große Modelle auf deinen Mac passen.

Rund um KI-Modelle

Sprachmodell
Ein KI-Programm, das Text Stück für Stück fortsetzt und so Antworten schreibt.
Token
Das kleinste Stück, das ein Sprachmodell erzeugt – ungefähr ein Wortteil.
tok/s (Tokens pro Sekunde)
Wie viele Tokens pro Sekunde entstehen. Im Dashboard: TG TPS. Mehr ist besser.
TTFT (Time to First Token)
Wartezeit vom Absenden bis zum ersten Token, im Dashboard in Millisekunden. Weniger ist besser.
Kontext
Alles, was das Modell bei einer Anfrage liest: deine Frage, der bisherige Chat, eingefügte Dateien. Gemessen in Tokens, zum Beispiel 32K = rund 32.000.
Hugging Face
Die größte Plattform für frei verfügbare KI-Modelle. Jedes Modell hat eine Repository-ID der Form Anbieter/Modellname.
Quantisierung (4 Bit)
Verkleinerung eines Modells, damit es in weniger Speicher passt. oQ4e im Namen steht für eine 4-Bit-Variante von oMLX.

oMLX und Splash

oMLX
Kostenlose Mac-App mit Server unter localhost:8000, die lokale Sprachmodelle lädt, verwaltet und ausführt. (Steuerzentrale)
MLX
Apples Rechenbibliothek für Apple-Chips. oMLX bringt sie mit; du installierst sie nicht separat.
Engine (Motor)
Der Programmteil, der ein Modell tatsächlich rechnen lässt. oMLX hat einen eingebauten MLX-Motor.
Splash
Eigenständige Engine von Inco AI, die oMLX für bestimmte Modelle statt des eingebauten Motors nutzen kann. (zweiter Motor)
Externe Engine
Der oMLX-Schalter, mit dem ein Modell über Splash läuft. Im Dashboard: Use external engine. oMLX startet Splash dann selbst im Hintergrund.
Zielmodell
Das große Modell, das die Antwort verantwortet, hier Jundot/Qwen3.8-27B-oQ4e-mtp. (Lektorin)
Draft (DFlash2)
Kleines Zusatzmodell, das Tokens vorrät, hier incoai/Qwen3.8-27B-DFlash2. (Assistent)
Speculative Decoding
Verfahren, bei dem ein Draft mehrere Tokens vorrät und das Zielmodell sie in einem Durchgang prüft. Gleiche Antwort, schneller.
MTP (Multi-Token-Prediction)
oMLX’ eigenes Vorrat-Verfahren ohne Splash. Es ist die Baseline, gegen die Splash antritt.
Splash-Komplettpaket
Pakete wie incoai/Qwen3.8-27B-Splash, gedacht für Splash ohne oMLX. oMLX kann sie nicht nutzen.
Baseline
Der Messwert ohne Splash, mit dem du die Messung mit Splash vergleichst.
API-Key
Dein selbst gewähltes Passwort für oMLX. Schützt den Server und ist der Login fürs Web-Dashboard.
Web-Dashboard
Die Oberfläche von oMLX im Browser unter http://localhost:8000/admin.

Frag nach

  1. Markiere einen Begriff und notiere als Kommentar, was dir daran noch unklar ist.
  2. Öffne deinen eigenen KI-Agenten und gib ihm diese Seite als Kontext: Lass ihn die HTML-Datei lesen oder füge den Seiteninhalt in den Chat ein.
  3. Klicke oben rechts auf „Kopieren“. Dadurch landet die markierte Textstelle samt Kommentar als JSON in der Zwischenablage.
  4. Füge dieses JSON in den Chat deines KI-Agenten ein.
  5. Jetzt könnt ihr gezielt an deiner markierten Frage weiterarbeiten.
