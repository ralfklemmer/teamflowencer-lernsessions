Kapitel 03 · Installation, Teil 1

oMLX installieren und starten

oMLX ist eine ganz normale Mac-App. Du lädst sie herunter, ziehst sie in den Programme-Ordner und richtest sie in einem Willkommens-Dialog ein.

10–15 Minutenkein Terminal nötigBrowser

Dein Ergebnis

oMLX läuft, ist mit deinem eigenen API-Key geschützt, und du bist im Web-Dashboard angemeldet – der Oberfläche, über die du in Kapitel 04 und 05 alles einstellst.

Gut zu wissen

Die Oberfläche von oMLX ist englisch. Klickpfade stehen deshalb wörtlich hier, zum Beispiel Models → Downloader. Die Erklärungen sind deutsch. Geprüft wurde mit oMLX 0.7.1rc1; neuere Versionen können kleine Abweichungen zeigen.

1 · Die richtige Datei herunterladen

  1. Öffne die Release-Seite von oMLX: github.com/jundot/omlx/releases. eine Liste von Versionen, die neueste oben.
  2. Wähle die neueste stabile Version. Erkennbar daran, dass im Namen weder dev noch rc steht – zum Beispiel 0.7.2. Versionen mit dev oder rc sind Vorabversionen für Tester.
  3. Klappe bei dieser Version Assets auf und lade die Datei, die zu deinem macOS passt:
    Dein macOSDatei endet auf
    26 oder 27 (nötig für Splash)-macos26-27.dmg
    15 Sequoia (nur oMLX, kein Splash)-macos15-sequoia.dmg
    eine Datei wie oMLX-0.7.2-macos26-27.dmg in deinem Ordner Downloads.

2 · Installieren

  1. Öffne den Ordner Downloads im Finder und doppelklicke auf die .dmg-Datei. ein Fenster mit dem oMLX-Symbol und einem Ordner Applications (Programme).
  2. Ziehe das oMLX-Symbol mit der Maus auf den Ordner Applications.
  3. Öffne Programme im Finder und doppelklicke auf oMLX.

macOS blockiert den Start?

Erscheint eine Meldung, dass die App nicht geöffnet werden kann, öffne Systemeinstellungen → Datenschutz & Sicherheit, scrolle nach unten und klicke bei oMLX auf Dennoch öffnen. Das ist der Standardweg für Apps, die nicht aus dem App Store stammen.

3 · Der Willkommens-Dialog

Beim ersten Start begrüßt dich oMLX mit „Local AI, no more waiting.“

  1. Klicke auf Get Started. die Seite Local server: „Choose where models live, pick a port, and create the API key …“
  2. Ordner: Lass die Vorschläge stehen. oMLX legt in deinem Benutzerordner einen versteckten Ordner .omlx an – darin landen Einstellungen und Modelle.
  3. Port: Lass 8000 stehen. Der Port ist wie eine Zimmernummer: Programme auf deinem Mac finden oMLX unter localhost:8000.
  4. API-Key: Denk dir ein Passwort aus und trage es bei Create an API key ein. Regeln: mindestens 4 Zeichen, keine Leerzeichen, keine Umlaute. Nimm etwas Langes, zum Beispiel aus einem Passwort-Manager. der Hinweis „This key is also your Web Dashboard login password.“ – der Key ist also auch dein Login fürs Dashboard.
  5. Klicke auf Start Server. kurz „Starting Server…“, dann „All set!“ und „Server started. Dashboard is ready.“
  6. Klicke auf Open Web Dashboard. dein Browser öffnet eine Anmeldeseite. Trage deinen API-Key ein und melde dich an.

API-Key gut aufbewahren

Speichere den Key in deinem Passwort-Manager oder in der Schlüsselbundverwaltung. Du brauchst ihn für jede Anmeldung im Dashboard. Zeig ihn nicht in Screenshots oder Videos.

4 · Wo oMLX wohnt

oMLX hat kein großes Fenster. Es lebt als kleines Symbol oben rechts in der Menüleiste. Ein Klick darauf zeigt unter anderem:

MenüpunktWofür
Start Server / Stop ServeroMLX ein- und ausschalten
Open Web Dashboarddie Oberfläche im Browser öffnen
Settings…App-Einstellungen, zum Beispiel automatischer Serverstart
Quit oMLXoMLX ganz beenden

Das Dashboard erreichst du jederzeit auch direkt im Browser: http://localhost:8000/admin.

5 · Das Dashboard kennenlernen

Oben im Dashboard findest du sechs Reiter. Für dieses Tutorial brauchst du vier davon:

ReiterWas du dort tustKapitel
ModelsModelle herunterladen (Downloader) und verwalten (Manager)04
SettingsSplash als externe Engine finden lassen, Modell-Einstellungen04, 05
Chatmit einem Modell schreiben05
BenchGeschwindigkeit messen05

Auf der Startseite (Dashboard) erscheint vielleicht „New here? You don't have any models yet.“ mit Modell-Empfehlungen. Klicke auf Not now: Du lädst in Kapitel 04 gezielt die Modelle, die mit Splash funktionieren.

Optional: Lebenszeichen im Terminal

Wenn du dein neues Terminal-Wissen üben willst: Dieser Befehl fragt oMLX, ob es läuft. Er ändert nichts.

curl -s http://localhost:8000/health

eine Zeile, die mit {"status":"healthy" beginnt.

Frag nach

  1. Markiere eine relevante Stelle und notiere deine Frage, deinen Einwand oder deinen Praxisfall als Kommentar.
  2. Öffne deinen eigenen KI-Agenten (zum Beispiel ChatGPT oder Claude) und gib ihm diese Seite als Kontext: Lass ihn die Lesson-Datei lesen oder füge den Seiteninhalt in den Chat ein.
  3. Klicke oben rechts auf „Kopieren“. Dadurch landet die markierte Textstelle samt Kommentar als JSON in der Zwischenablage.
  4. Füge dieses JSON in den Chat deines KI-Agenten ein.
  5. Jetzt könnt ihr gezielt an deiner markierten Frage weiterarbeiten.
