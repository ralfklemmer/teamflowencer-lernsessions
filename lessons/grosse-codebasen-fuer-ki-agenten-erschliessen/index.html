Große Codebasen für KI-Agenten erschließen

Ein kontrollierter Kontextzugriff, damit dein Agent auch in großen Repositories gezielt helfen kann.

4 Kapitelca. 45–60 Minutenread-only Einstieg

Das erreichst du

Du baust ein Setup, mit dem ein KI-Agent zuerst die relevanten Bereiche einer Codebase findet und danach nur die benötigten Details abruft – ohne das gesamte Repository in das Context Window zu laden. Anschließend kannst du anhand sichtbarer Tool-Ergebnisse prüfen, ob dieser Zugriff wirklich funktioniert.

Warum dieser Ansatz?

Ein großes Context Window allein sagt einem Agenten noch nicht, welcher Teil einer Codebase für deine Aufgabe wichtig ist. Eine vollständige Übergabe des Repositories erzeugt viel Kontext, aber noch keine gute Suchstrategie.

Deshalb wird der Kontext schrittweise aufgebaut:

deine fachliche Aufgabe ↓ Repo Map liefert den begrenzten Überblick ↓ Serena nutzt den Language Server für gezielte Code-Beziehungen ↓ nur die jetzt benötigten Details gelangen zum Agenten ↓ Tool-Ergebnisse machen den Zugriff überprüfbar

Die Übersicht zeigt dir zunächst nur diese Nutzenkette. Im ersten Kapitel lernst du, warum Repo Map und Serena unterschiedliche Aufgaben übernehmen und weshalb der Language Server je nach Programmiersprache eine zentrale Rolle spielt.

Setup von null bis funktionsfähig

Die Kapitel enthalten alle Befehle, Konfigurationen, erwarteten Ergebnisse und Prüfschritte. Du musst keine weitere Datei dieses Projekts öffnen. Arbeite in der Reihenfolge 01 → 04 und beginne auf einem sauberen Git-Stand.

Wichtige Grenze

Eine gute Repo Map und korrekte Serena-Treffer beweisen, dass die Kontext-Pipeline funktioniert. Sie beweisen noch nicht, dass eine spätere Codeänderung fachlich richtig ist.

Frag nach

  1. Markiere eine relevante Stelle und notiere deine Frage, deinen Einwand oder deinen Praxisfall als Kommentar.
  2. Öffne deinen eigenen KI-Agenten und gib ihm diese Seite als Kontext: Lass ihn die HTML-Datei lesen oder füge den Seiteninhalt in den Chat ein.
  3. Klicke oben rechts auf „Kopieren“. Dadurch landet die markierte Textstelle samt Kommentar als JSON in der Zwischenablage.
  4. Füge dieses JSON in den Chat deines KI-Agenten ein.
  5. Jetzt könnt ihr gezielt an deiner markierten Frage weiterarbeiten.
