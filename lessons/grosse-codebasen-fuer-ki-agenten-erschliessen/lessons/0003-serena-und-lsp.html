Kapitel 03 · Installation

Serena in Pi einrichten

Projekt indexieren, Serena über MCP anbinden und den ersten semantischen Treffer erzeugen.

20 MinutenLanguage Serverread-only Tools

Dein Ergebnis

Pi kann Serena starten, ein Symbol aus dem lokalen Projekt finden und dessen relativen Pfad als Tool-Ergebnis zurückgeben.

1 · Laufzeit und Serena installieren

Für Java muss zusätzlich java -version funktionieren. Für andere Sprachen benötigt Serena den jeweils unterstützten Language Server.

command -v uv git java

uv tool install -p 3.13 'serena-agent==1.7.0'
command -v serena
serena --version
serena init

Erwartung: serena --version meldet 1.7.0.

2 · Dein Projekt indexieren

Wechsle in das Git-Root. Ersetze java, wenn du eine andere von Serena unterstützte Sprache verwendest.

cd /pfad/zu/deinem/git-repository
git rev-parse --show-toplevel

serena project create --language java .
serena project index .
serena project health-check .

Erwartung: Der Health-Check endet ohne Werkzeugfehler. Serena erzeugt dafür das lokale Verzeichnis .serena/.

for pattern in '.serena/' '.mcp.json'; do
  grep -qxF "$pattern" .git/info/exclude || \
    printf '%s\n' "$pattern" >> .git/info/exclude
done

git status --short

3 · Den MCP-Adapter für Pi installieren

pi install npm:pi-mcp-adapter@2.27.0
pi list

Erwartung: pi-mcp-adapter@2.27.0 erscheint in der Paketliste.

4 · Projektkonfiguration erzeugen

Der folgende Befehl liest den echten Serena-Pfad und das echte Git-Root direkt vom Rechner und schreibt daraus .mcp.json. So musst du keinen langen Pfad von Hand übertragen.

SERENA_BIN="$(command -v serena)"
PROJECT_ROOT="$(git rev-parse --show-toplevel)"

python3 - "$SERENA_BIN" "$PROJECT_ROOT" <<'PY'
import json
import sys
from pathlib import Path

serena_bin, project_root = sys.argv[1:]
config = {
    "settings": {
        "toolPrefix": "server",
        "scriptMode": False,
        "hostConfigDiscovery": "off",
        "sampling": False,
        "elicitation": False,
        "outputGuard": True,
    },
    "mcpServers": {
        "serena": {
            "command": serena_bin,
            "args": [
                "start-mcp-server",
                "--context", "ide",
                "--project-from-cwd",
                "--open-web-dashboard", "false",
            ],
            "cwd": project_root,
            "lifecycle": "lazy",
            "directTools": [
                "initial_instructions",
                "get_symbols_overview",
                "find_symbol",
                "find_referencing_symbols",
                "find_implementations",
                "get_diagnostics_for_file",
                "search_for_pattern",
            ],
            "debug": False,
        }
    },
}
Path(".mcp.json").write_text(json.dumps(config, indent=2) + "\n")
PY

lazy bedeutet: Serena startet erst beim ersten Serena-Aufruf. Die kleine Tool-Auswahl hält mutierende Werkzeuge zunächst aus dem direkten Arbeitsbereich heraus.

5 · Serena erstmals aus Pi aufrufen

pi

Prüfe in Pi zuerst /mcp. Vor dem ersten Aufruf darf Serena wegen lazy noch nicht verbunden sein. Wähle dann einen Klassennamen, den du in deinem Projekt sicher kennst, und ersetze BEKANNTES_SYMBOL:

Verwende ausschließlich Serena und verändere keine Dateien.
Rufe zuerst initial_instructions auf. Finde danach BEKANNTES_SYMBOL
und nenne relativen Dateipfad sowie Symbolart. Belege die Antwort
nur mit den sichtbaren Serena-Tool-Ergebnissen.
