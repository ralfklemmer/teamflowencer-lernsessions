Kapitel 02 · Installation, Teil 1

Repo Map in Pi einrichten

Aider erzeugt die Karte lokal. Eine kleine Pi-Extension macht sie als repo_map-Werkzeug verfügbar.

15 MinutenmacOS/LinuxGit-Repository

Dein Ergebnis

Pi kann in deinem Git-Repository einen echten repo_map-Aufruf ausführen und erhält konkrete Pfade und Symbole.

Was dabei Tokens kostet – und was nicht

Aider selbst stellt bei --show-repo-map keine LLM-Anfrage. Parsing, Ranking und Rendering laufen lokal. Das bedeutet aber nicht „keine Tokens“: Tool-Schema und Tool-Ausgabe werden Pi bereitgestellt. Die Tool-Ausgabe beansprucht dadurch Pi-Kontext und gelangt in einen Modell-Request des Agent Loops.

Der Parameter map_tokens ist ein ungefähres Ziel für Aiders gerenderte Map, keine Garantie für eine exakt gleich große Ausgabe. Er steuert das Zielbudget; Tokenisierung, Ranking und Ausgabeformat beeinflussen den tatsächlichen Umfang.

Voraussetzungen prüfen

command -v git node npm uv

git --version
node --version
uv --version

Jeder command -v-Aufruf muss einen Pfad liefern. Fehlt uv auf macOS, kannst du es mit brew install uv installieren. Node.js und npm installierst du über den Paketmanager deiner Plattform.

Pi installieren

npm install -g --ignore-scripts @earendil-works/pi-coding-agent@0.84.2
command -v pi
pi --version

Aider installieren

Diese Version wurde für das Tutorial geprüft:

uv python install 3.12
uv tool install --force --python python3.12 --with pip 'aider-chat==0.86.2'

command -v aider
aider --version
aider --help | grep -- '--show-repo-map'

Erwartung: Aider meldet Version 0.86.2, und die Hilfe enthält --show-repo-map.

Die Repo-Map-Extension installieren

Die Extension wird als Quelle auf GitHub verteilt. Installiere das Release v1.0.0 und pinne dabei den vollständigen Commit-SHA – nie main, einen Branch oder nur einen beweglichen Tag:

pi install git:https://github.com/ralfklemmer/pi-repo-map-extension@7ceeb5ec466a24a811f0a1c4b7482855fc7d3521

Pi lädt das Repository bei diesem Aufruf, checkt exakt den gepinnten Stand aus und kann gemäß seiner Paketverwaltung npm install --omit=dev ausführen; das mitgelieferte install.sh läuft dabei nicht. Das Repository steht unter Apache-2.0 – Mensch-lesbarer Release-Stand: Tag v1.0.0, Commit 7ceeb5ec466a24a811f0a1c4b7482855fc7d3521.

Vertrauen und Updates

Pi-Pakete laufen mit deinen Benutzerrechten. Sieh dir den Code am gepinnten Commit an, bevor du installierst, und aktualisiere nur bewusst auf einen neuen, geprüften vollständigen SHA – nicht auf main und nicht automatisch.

Dein Repository vorbereiten

cd /pfad/zu/deinem/git-repository
git rev-parse --show-toplevel
git status --short

grep -qxF '.aider.tags.cache.v4/' .git/info/exclude || \
  printf '%s\n' '.aider.tags.cache.v4/' >> .git/info/exclude

Notiere vorhandene Änderungen. Der lokale Ausschluss verhindert, dass Aiders Cache als ungetracktes Projektartefakt erscheint; er verändert keine getrackte Datei.

Den ersten echten Aufruf ausführen

pi

Gib Pi danach diesen read-only Auftrag:

Rufe repo_map für das aktuelle Repository mit map_tokens=2048 auf.
Verändere keine Dateien. Nenne drei tatsächlich sichtbare Pfade oder
Symbole und eine Detailfrage, die diese begrenzte Map offenlässt.

Öffne den sichtbaren Tool-Call. Das Parameterschema sollte ungefähr diesen Ausschnitt zeigen:

{
  "map_tokens": 2048
}

Erwartete Beobachtungen

Die Map enthält mehr oder weniger als exakt 2.048 Modell-Tokens. Ist der Aufruf damit defekt?

Wenn nur eine Zusammenfassung erscheint

Prüfe, ob im Pi-Transkript wirklich der Tool-Call sichtbar ist. Eine vom Modell formulierte Beschreibung ohne Tool-Ergebnis belegt nicht, dass die Extension funktioniert.

Frag nach

  1. Markiere eine relevante Stelle und notiere deine Frage, deinen Einwand oder deinen Praxisfall als Kommentar.
  2. Öffne deinen eigenen KI-Agenten und gib ihm diese Seite als Kontext: Lass ihn die Lesson-Datei lesen oder füge den Seiteninhalt in den Chat ein.
  3. Klicke oben rechts auf „Kopieren“. Dadurch landet die markierte Textstelle samt Kommentar als JSON in der Zwischenablage.
  4. Füge dieses JSON in den Chat deines KI-Agenten ein.
  5. Jetzt könnt ihr gezielt an deiner markierten Frage weiterarbeiten.
