Kapitel 02 · Installation

Repo Map in Pi einrichten

Aider erzeugt die Karte. Eine kleine Pi-Extension macht sie als repo_map-Werkzeug verfügbar.

15 MinutenmacOS/LinuxGit-Repository

Dein Ergebnis

Pi kann in einem beliebigen Git-Repository einen echten repo_map-Aufruf ausführen und erhält konkrete Pfade und Symbole.

0 · Voraussetzungen prüfen

command -v git node npm uv

git --version
node --version
uv --version

Jeder command -v-Aufruf muss einen Pfad liefern. Fehlt uv auf macOS, kannst du es mit brew install uv installieren. Fehlen Node und npm, installiere ein aktuelles Node.js-Paket über deinen Paketmanager.

1 · Pi installieren

npm install -g --ignore-scripts @earendil-works/pi-coding-agent
command -v pi
pi --version

2 · Aider installieren

Diese Version wurde für das Tutorial geprüft:

uv python install 3.12
uv tool install --force --python python3.12 --with pip 'aider-chat==0.86.2'

command -v aider
aider --version
aider --help | grep -- '--show-repo-map'

Erwartung: Aider meldet Version 0.86.2, und die Hilfe enthält --show-repo-map.

3 · Die Repo-Map-Extension installieren

Repo-Map-Extension herunterladen, entpacken und das Verzeichnis an einen dauerhaften Ort legen. Pi referenziert diesen Ordner; verschiebe ihn nach der Installation nicht.

cd /pfad/zum/pi-repo-map-extension
chmod +x install.sh
./install.sh

Der Installer prüft pi, git und aider und registriert anschließend das lokale Paket in Pi.

4 · Ein Repository vorbereiten

cd /pfad/zu/deinem/git-repository
git rev-parse --show-toplevel
git status --short

grep -qxF '.aider.tags.cache.v4/' .git/info/exclude || \
  printf '%s\n' '.aider.tags.cache.v4/' >> .git/info/exclude

Beginne möglichst mit leerer Ausgabe von git status --short. Der lokale Ausschluss verhindert, dass Aiders Indexcache deinen Working Tree verschmutzt.

5 · Den ersten echten Aufruf ausführen

pi

Gib Pi danach diesen Auftrag:

Erzeuge mit repo_map eine globale Übersicht dieses Repositories mit
2048 Map-Tokens. Verändere keine Dateien. Nenne drei sichtbare
Einstiegssymbole und eine Detailfrage, die die Map nicht beantworten kann.

Erwartete Beobachtungen

Wenn nur eine Zusammenfassung erscheint

Prüfe, ob im Pi-Transkript wirklich der Tool-Call sichtbar ist. Eine vom Modell formulierte Beschreibung ohne Tool-Ergebnis beweist nicht, dass die Extension funktioniert.

Frag nach

  1. Markiere eine relevante Stelle und notiere deine Frage, deinen Einwand oder deinen Praxisfall als Kommentar.
  2. Öffne deinen eigenen KI-Agenten und gib ihm diese Seite als Kontext: Lass ihn die Lesson-Datei lesen oder füge den Seiteninhalt in den Chat ein.
  3. Klicke oben rechts auf „Kopieren“. Dadurch landet die markierte Textstelle samt Kommentar als JSON in der Zwischenablage.
  4. Füge dieses JSON in den Chat deines KI-Agenten ein.
  5. Jetzt könnt ihr gezielt an deiner markierten Frage weiterarbeiten.
