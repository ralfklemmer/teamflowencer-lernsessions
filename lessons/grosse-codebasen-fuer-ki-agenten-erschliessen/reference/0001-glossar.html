Glossar: Kontextarchitektur

Begriffe so eng definieren, dass Tool-Befund und Modellinterpretation getrennt bleiben.

BegriffArbeitsdefinitionNicht verwechseln mit
Agent LoopWiederholung aus Modellentscheidung, Tool-Aufruf, Beobachtung und nächster Entscheidung.Einmaliger Prompt oder autonome Korrektheit.
Context WindowBegrenzter Eingaberaum, den das Modell in einem Request verarbeiten kann.Repository-Index oder garantiert nutzbare Aufmerksamkeit.
Repo MapKompakte Textdarstellung priorisierter Dateien, Symbole und ausgewählter Definitionszeilen.Vollständiger Syntaxbaum, Call Graph oder Architekturmodell.
map_tokensUngefähres Zielbudget, das Aider beim Rendern der Repo Map anstrebt.Garantie einer exakten Ausgabegröße.
Tree-sitterParsing-System, aus dessen sprachspezifischen Abfragen Aider Definitionen und Referenzen gewinnen kann.Die fertige Repo Map oder vollständige Typauflösung.
SymbolBenannter Codebaustein wie Klasse, Methode, Feld oder Interface.Beliebiger Texttreffer.
ReferenzCodeposition, die ein aufgelöstes Symbol verwendet.Gleichlautende Zeichenfolge.
Language ServerSeparater Prozess mit sprachspezifischer Code-Intelligence hinter einem standardisierten Protokoll.MCP-Server oder LLM.
LSPJSON-RPC-basiertes Protokoll zwischen Entwicklungswerkzeug und Language Server.Der Sprachindex selbst.
JDTLSLanguage Server für Java und praktisch validierter Pfad dieses Tutorials.Beleg, dass andere Sprachen identisch funktionieren.
SerenaWerkzeugschicht, die Symboloperationen über ein Backend wie LSP als Agent-Tools anbietet.Eigenes Sprachmodell.
MCPProtokoll für Host–Client–Server-Kommunikation über Tools, Resources und Prompts.Language Server oder Sicherheits-Sandbox.
Tool SchemaBeschreibung und Parameterschema, anhand derer das Modell ein Tool auswählen und aufrufen kann.Tool-Ergebnis; beides beansprucht Kontext.
Lazy LifecycleServerstart beim ersten benötigten Aufruf mit kontrolliertem Shutdown am Sitzungsende.Stets laufender Daemon.
EvidenzBeobachtbarer Tool-Call, Tool-Befund oder manueller Codefund, der eine Aussage stützt.Selbstbewusste Modellformulierung.

Token-Präzision

Aider sendet für --show-repo-map selbst keine LLM-Anfrage. Tool-Schema und erzeugte Map gelangen jedoch in Pis Agent Loop und beanspruchen dort Modellkontext.
