Lokales Setup: Kurz-Runbook

Gepinnte Versionen, Java-/JDTLS-Pfad und sichtbare Prozess- sowie Git-Invarianten.

Lokal verifiziert · 2026-08-24

Pi 0.84.2 · Aider 0.86.2 · Serena 1.7.0 · uv 0.11.25 · Java mit JDTLS. Repo Map, Serena-Health-Check und ein bekannter Symboltreffer waren erfolgreich. Andere Sprachpfade wurden für dieses Tutorial nicht praktisch geprüft.

Voraussetzungen und Versionen

command -v pi aider serena uv java git
pi --version
aider --version
serena --version
uv --version
java -version
git --version

Gepinnte Installation

uv python install 3.12
uv tool install --force --python python3.12 --with pip 'aider-chat==0.86.2'
uv tool install -p 3.13 'serena-agent==1.7.0'
serena init

npm install -g --ignore-scripts @earendil-works/pi-coding-agent@0.84.2
pi install npm:pi-mcp-adapter@2.27.0

Serena Installation · Aider Installation. Drittcode vor Installation prüfen; Pi-Pakete laufen mit Benutzerrechten.

Die Repo-Map-Extension für den repo_map-Nachweis unten ist hier nicht enthalten: Sie wird aus der gepinnten GitHub-Quelle installiert – Befehl, Commit-SHA und Release-Record stehen in Kapitel 02.

Java-Projekt vorbereiten

cd /authentisch/ermittelter/pfad/zum/projekt
git rev-parse --show-toplevel
serena project create --language java .
serena project index .
serena project health-check .
git status --short

Lokale Artefakte über .git/info/exclude ausschließen: .aider.tags.cache.v4/, .serena/, .mcp.json. Die vollständige .mcp.json-Erzeugung steht in Kapitel 03.

Pi-Anbindung: Invarianten

  • absoluter, per command -v serena ermittelter Befehl,
  • authentischer Projektpfad als cwd,
  • --context ide gegen Tool-Dopplung,
  • --project-from-cwd für das aktive Repository,
  • lifecycle: "lazy" gegen Doppelstarts,
  • explizite direkte read-only Serena-Werkzeuge.

Minimaler read-only Nachweis

ps -axo pid=,ppid=,command= | \
  grep -E '[s]erena start-mcp-server|[o]rg\.eclipse\.equinox\.launcher' || true
git status --short

Kein blindes Cleanup

Niemals pauschal alle Java-Prozesse beenden. Prozess, Startzeit und vollständiges Kommando prüfen; nur eindeutig zuordenbare PIDs terminieren.
